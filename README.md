# Tres Horizontes

App personal de gestión de objetivos a 3, 6 y 12 meses, cuyo núcleo es:

**objetivo → plan → microacción diaria → replanificación con IA**

## Documentación

- [`docs/tres-horizontes.html`](docs/tres-horizontes.html) — propuesta completa de
  arquitectura funcional y técnica: pantallas, flujo de usuario, alcance del MVP,
  stack, modelo de datos, integración de IA, algoritmo de generación de
  microacciones diarias, motor de replanificación, UX/UI y estimación de esfuerzo.

El documento se publica también como artifact para lectura en navegador.
